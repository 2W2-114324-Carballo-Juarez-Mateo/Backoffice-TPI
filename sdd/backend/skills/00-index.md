# Skills (Backend) — Índice

> Las **Skills** son procedimientos concretos: "cómo se hace X". Son recetas paso a paso; cada una asume que ya leíste el `docs/` correspondiente.

| Skill | Para qué |
|---|---|
| `SKILL-build-test.md` | Compilar, testear (unit + integración) y ejecutar el proyecto |
| `SKILL-endpoint.md` | Agregar un endpoint REST completo (de punta a punta) |
| `SKILL-evento.md` | Publicar y consumir un evento de dominio con Outbox |
| `SKILL-caso-uso.md` | Estructurar un caso de uso (Command) y aplicar un patrón |
| `SKILL-despliegue.md` | Docker Compose, migraciones Flyway, config por ambiente |

> Regla transversal: después de cada tarea, verificá que `sdd/` siga reflejando el código (actualizá `docs/`, `rules/` o `skills/` si cambió algo).
