# 05 — UI compartida y consistencia visual

## `@tup/ui`

- **Design tokens** (variables CSS: color, spacing, tipografía, radios) + **componentes** (botones, tablas, forms, navbar, badges).
- Publicada como paquete npm **versionado (semver)**: breaking → major.
- Consumo **solo** desde la librería: no se definen estilos propios que rompan el token.
- **CI:** valida que la librería compile y que las apps usen versiones compatibles.

## Reglas de consistencia

- Tokens en variables CSS; no colores sueltos.
- Componentes UI desde la librería; no reimplementarlos por app.
- Si falta un componente, se agrega a `@tup/ui` (con su versión), no se hackea localmente.
- Las apps solo consumen; el dueño de la librería define el changelog.
