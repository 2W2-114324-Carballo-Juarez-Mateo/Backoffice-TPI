[G06-HU06] — Gestión del golden set y ejecución de revisión

> **Épica:** EP-03 · Modelos LLM y Golden Set
> **En simple:** el sistema prueba un modelo de IA contra un conjunto de respuestas de referencia y calcula qué tan lejos estuvo, dejando el resultado guardado.

Descripción (Como / Quiero / Para)
Como: ADMIN y Sistema
Quiero: ejecutar la revisión de un modelo contra las respuestas de referencia y guardar el resultado
Para: saber con datos si un modelo es confiable antes de usarlo, y poder mostrar el resultado

Notas / Observaciones
Reglas de negocio:
- El golden set (respuestas de referencia) lo define la cátedra.
- La revisión ejecuta el modelo sobre los casos y calcula el error promedio (cuánto se desvía de la referencia).
- El resultado de cada revisión queda guardado para consultarlo después.
- Una revisión pendiente no habilita nada por sí sola: la habilitación depende de la tolerancia (US-07).
Validaciones:
- El modelo a revisar debe existir.
- Debe haber casos de referencia cargados.
Datos obligatorios: modelo a revisar, casos de referencia, resultado del error promedio.
Performance: la revisión se procesa en segundo plano sin afectar a los usuarios.
Seguridad: solo ADMIN puede ver los resultados detallados.
Accesibilidad: los resultados se muestran con formato claro.
Otros: —

Criterios de Aceptación (CA)
CA1: Al ejecutar la revisión, el sistema guarda el resultado con el error promedio calculado.
CA2: El error se calcula sobre todos los casos de referencia.
CA3: Los resultados quedan disponibles para consulta.
Extras (opcional): —

BDD (mínimo 3 escenarios)
Característica: Revisión de un modelo contra el golden set

Escenario 1: Revisión exitosa
Dado: que hay casos de referencia cargados y un modelo candidato
Cuando: se ejecuta la revisión
Entonces: el sistema calcula el error promedio y guarda el resultado

Escenario 2: Sin casos de referencia
Dado: que no hay casos de referencia cargados
Cuando: se intenta revisar un modelo
Entonces: la revisión no se ejecuta y se informa que faltan los casos

Escenario 3: Consulta de resultados
Dado: que hay revisiones guardadas
Cuando: el ADMIN consulta los resultados
Entonces: ve el detalle de cada revisión (modelo, error promedio, fecha)

Prototipo
Mock API / Swagger:
- POST /api/administration/llm/golden-set/runs → ejecutar revisión
- GET  /api/administration/llm/golden-set/runs → ver resultados

Riesgos y mitigación (opcional): depende del golden set de la cátedra; si no está definido, la revisión no puede validarse
