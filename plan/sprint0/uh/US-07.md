[G06-HU07] — Aprobación por tolerancia (PAR-14) y fallback por deriva

> **Épica:** EP-03 · Modelos LLM y Golden Set
> **En simple:** un modelo solo se habilita si su error está dentro de lo permitido; y si con el tiempo empieza a fallar, el sistema lo saca solo y avisa.

Descripción (Como / Quiero / Para)
Como: ADMIN y Sistema
Quiero: que un modelo solo se habilite si el error está dentro de la tolerancia configurada y que, si se desvía, se pase a un respaldo y se avise
Para: asegurar la equidad de las calificaciones y proteger a los alumnos ante una degradación del modelo

Notas / Observaciones
Reglas de negocio:
- La tolerancia se define en un parámetro configurable (PAR-14).
- Si el error promedio está dentro de la tolerancia, el modelo queda "aprobado" y puede habilitarse.
- Si supera la tolerancia, el modelo queda rechazado y no se habilita.
- Una revisión periódica controla al modelo en uso; si se desvía, se pasa a un respaldo y se emite una alerta crítica.
Validaciones:
- El resultado de la revisión debe existir (US-06).
- La tolerancia debe ser un valor válido.
Datos obligatorios: resultado de la revisión, tolerancia (PAR-14).
Performance: la revisión periódica corre en segundo plano.
Seguridad: solo ADMIN puede forzar la habilitación o ver el detalle.
Accesibilidad: el estado del modelo y las alertas se muestran con formato claro.
Otros: la alerta de deriva se envía a notificaciones.

Criterios de Aceptación (CA)
CA1: Un modelo con error dentro de la tolerancia queda aprobado y puede activarse.
CA2: Un modelo con error mayor a la tolerancia queda rechazado y no puede activarse.
CA3: En la revisión periódica, si el modelo activo se desvía, pasa a respaldo y se emite la alerta.
Extras (opcional): —

BDD (mínimo 3 escenarios)
Característica: Aprobación por tolerancia y fallback por deriva

Escenario 1: Modelo aprobado
Dado: que la tolerancia permitida es de 5 puntos
Cuando: el error promedio del modelo es 3,4
Entonces: el modelo queda aprobado y puede habilitarse

Escenario 2: Modelo rechazado
Dado: un modelo con error promedio de 7,8
Cuando: supera la tolerancia
Entonces: el modelo queda rechazado y no puede habilitarse

Escenario 3: Deriva del modelo activo
Dado: que la revisión periódica del modelo en uso da un error de 6,2
Cuando: supera la tolerancia
Entonces: el sistema pasa al respaldo y emite la alerta crítica
