[G06-HU09] — Exportación de reportes

Descripción (Como / Quiero / Para)
Como: ADMIN o PROFESOR
Quiero: pedir que se genere un archivo (PDF o CSV) con los reportes y que me avisen cuando esté listo
Para: obtener constancias que se puedan usar fuera de la plataforma sin que la pantalla se trabe mientras se genera

Notas / Observaciones
Reglas de negocio:
- La solicitud de exportación no bloquea la interfaz: responde al instante y el archivo se genera en segundo plano.
- Al terminar, se avisa y se habilita un enlace temporal de descarga.
- El profesor solo puede exportar sus propias comisiones.
- El archivo PDF incluye un resumen de la operación (quién, cuándo) para que no se pueda alterar sin dejar rastro.
Validaciones:
- La solicitud debe indicar el tipo de reporte y el formato (PDF/CSV).
- Solo se exportan datos a los que el usuario tiene acceso.
Datos obligatorios: tipo de reporte, formato, alcance (comisión o consolidado).
Performance: la generación es en segundo plano; el archivo queda disponible dentro de un tiempo razonable.
Seguridad: RLS según el rol; enlaces temporales con fecha de vencimiento.
Accesibilidad: los archivos generados son legibles (el CSV se abre con texto claro).
Otros: el aviso de archivo listo se envía al sistema de notificaciones.

Criterios de Aceptación (CA)
CA1: Al solicitar una exportación, el sistema responde al instante con un identificador.
CA2: Al terminar de generarse, se avisa y queda disponible el enlace temporal.
CA3: El profesor solo exporta sus comisiones.
CA4: Si el enlace ya venció, la descarga responde 410 y no se puede acceder.
