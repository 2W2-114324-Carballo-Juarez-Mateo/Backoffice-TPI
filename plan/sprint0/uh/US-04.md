[G06-HU04] — Registro, sustitución y conmutación de proveedores de IA

Descripción (Como / Quiero / Para)
Como: ADMIN
Quiero: registrar y cambiar los proveedores o modelos de IA que usa la plataforma (por ejemplo, el que evalúa las entregas)
Para: elegir cuál se usa según costo y calidad, sin interrumpir las evaluaciones y sin exponer las claves secretas

Notas / Observaciones
Reglas de negocio:
- Solo el rol ADMIN gestiona proveedores y modelos de IA.
- Un modelo recién registrado queda "pendiente de revisión" y no se puede usar todavía.
- Solo un modelo puede estar activo a la vez para cada función (por ejemplo, un solo evaluador).
- Las claves de los proveedores se guardan cifradas y nunca se muestran completas.
- Al cambiar el modelo activo, se avisa a los servicios que lo usan.
Validaciones:
- La configuración del modelo debe ser válida (proveedor, versión, parámetros).
- No se puede activar un modelo que no haya pasado la revisión de calidad.
Datos obligatorios: proveedor, modelo, parámetros de uso (temperatura, límites).
Performance: el cambio de modelo activo se aplica sin interrumpir evaluaciones en curso.
Seguridad: claves cifradas y enmascaradas; solo ADMIN opera.
Accesibilidad: la pantalla de gestión es usable por teclado y cumple WCAG AA.
Otros: al conmutar se publica el aviso ModelProviderChanged.

Criterios de Aceptación (CA)
CA1: Al registrar un modelo, queda en estado "pendiente de revisión" y no se puede activar.
CA2: Al cambiar entre dos modelos aprobados, el nuevo queda activo y se publica el aviso con el modelo anterior y el nuevo.
CA3: Si se intenta activar un modelo no aprobado, responde 409 y no cambia nada.
