[G06-HU04] — Registro de proveedores y modelos de IA

> **Épica:** EP-03 · Modelos LLM y Golden Set
> **En simple:** el administrador carga un proveedor o modelo de IA (por ejemplo, el que evalúa entregas); queda guardado y en "espera de revisión", sin exponer las claves.

Descripción (Como / Quiero / Para)
Como: ADMIN
Quiero: registrar un proveedor o modelo de IA y ver el catálogo, indicando sus parámetros de uso
Para: tener disponible la opción para cuando haya que habilitarla, guardando las claves de forma segura

Notas / Observaciones
Reglas de negocio:
- Solo el rol ADMIN puede registrar proveedores y modelos.
- Un modelo recién cargado queda en estado "pendiente de revisión" y NO se puede activar todavía.
- Las claves de los proveedores se guardan cifradas y nunca se muestran completas.
- El catálogo muestra el estado de cada modelo (pendiente, aprobado, activo, retirado).
Validaciones:
- La configuración del modelo debe ser válida (proveedor, versión, parámetros).
- No se puede duplicar el mismo proveedor/modelo.
Datos obligatorios: proveedor, modelo, parámetros de uso (temperatura, límites).
Performance: el registro responde en menos de 100 ms (P95).
Seguridad: solo ADMIN opera; las claves se enmascaran en las respuestas.
Accesibilidad: la pantalla de registro es usable por teclado y cumple WCAG AA.
Otros: el modelo queda disponible para la revisión de calidad (US-06/07).

Criterios de Aceptación (CA)
CA1: Al registrar un modelo válido, responde 201, queda "pendiente de revisión" y no se puede activar.
CA2: El listado del catálogo muestra el estado de cada modelo.
CA3: Las claves nunca aparecen completas en ninguna respuesta.
Extras (opcional): —
