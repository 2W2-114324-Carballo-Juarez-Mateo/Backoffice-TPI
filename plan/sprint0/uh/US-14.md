[G06-HU14] — Umbrales de aviso y acceso al tablero

> **Épica:** EP-05 · Observabilidad, Reportes y Panel de Riesgo
> **En simple:** el administrador define cuándo un indicador está bajo lo esperado y el sistema avisa; solo el administrador puede ver el tablero.

Descripción (Como / Quiero / Para)
Como: ADMIN
Quiero: configurar umbrales para los indicadores y que el sistema avise cuando uno baja de lo esperado, con acceso solo para administradores
Para: reaccionar a tiempo ante un indicador fuera de rango

Notas / Observaciones
Reglas de negocio:
- Los umbrales de aviso los configura el ADMIN (por ejemplo, satisfacción mínima).
- Si un indicador cae por debajo del umbral, se emite el aviso.
- Solo el rol ADMIN accede al tablero y a los avisos.
Validaciones:
- El umbral debe ser un valor válido.
Datos obligatorios: indicador, umbral, valor actual.
Performance: el aviso se emite sin afectar a los usuarios.
Seguridad: solo ADMIN; otros roles reciben 403.
Accesibilidad: los avisos se muestran con texto claro.
Otros: el aviso se envía al sistema de notificaciones.

Criterios de Aceptación (CA)
CA1: El ADMIN puede configurar un umbral para un indicador.
CA2: Si el indicador baja del umbral, se emite el aviso.
CA3: Un rol que no es ADMIN recibe 403 al acceder.
Extras (opcional): —

BDD (mínimo 3 escenarios)
Característica: Umbrales y acceso al tablero

Escenario 1: Configuración de umbral
Dado: que el ADMIN está en el tablero
Cuando: fija el umbral de satisfacción mínima en 80%
Entonces: el umbral queda guardado y aplica al indicador

Escenario 2: Indicador bajo el umbral
Dado: que el umbral de satisfacción mínima es 80%
Cuando: el indicador baja a 74%
Entonces: se emite el aviso de indicador fuera de rango

Escenario 3: Acceso denegado
Dado: un usuario que no es ADMIN
Cuando: intenta abrir el tablero
Entonces: responde 403 y no muestra los indicadores
